用一双手，
控制你的演示。

Gesto 把摄像头变成你的遥控器：右手一挥翻页，双手比框就能读懂屏幕上的字并给出中文译文与讲解， 握拳关掉，张开手掌再叫回来。全程本地运行，不上传任何画面。

为什么是手势，而不是遥控器

讲课的人手里通常拿着翻页笔，但翻页笔只能翻页。屏幕上的字看不懂时，你只能停下来走回电脑。

🖐

翻页不用找东西

五指张开横向一挥就是翻页。连翻用食指+中指，冷却更短；挥手后的自然回位会被自动吞掉，不会误翻。

⛶

框住就读懂

双手比出取景框、稳住 1 秒，屏幕上那块区域被截图 → 本地 OCR → 中文译文 + 逐点讲解，弹在框旁边。

⚡

全部本地

手部关键点与文字识别都在本机跑（MediaPipe + RapidOCR），断网也能用。画面不出这台电脑。

✋

左右手分工

右手管翻页/关页面/复原，左手管缩放。系统按左右手分别判定，互不干扰。

↺

关错了能叫回来

握拳关掉面板后 6 秒内，张开手掌停住 0.8 秒，那块面板原样回来——类似浏览器的 Ctrl+Shift+T。

⌨

只发前台按键

不注入驱动、不 hook 系统。用普通按键模拟，PPT 是当前窗口才生效，退出程序即完全失效。

手势表

翻页/关闭/复原任何一只手都能用，不依赖左右手判定。位移阈值按手掌宽度自动归一化——手大手小、坐远坐近都不用重调；手在画面里太小时不判动作。

手动作效果说明
任意单手五指张开 · 向左划下一页掌心朝前横扫，斜挥也行（竖直跨度 ≤ 横向 1.6 倍）
任意单手五指张开 · 向右划上一页反向要停 0.2 秒；挥完的自然回位不会误翻
任意单手食指+中指 · 横向划连翻模式其余手指收拢，冷却 0.18s，适合连翻多页
任意单手握拳关面板 / 退放映2.5 秒内再抓一次 → 回桌面
任意单手张开手掌 · 停住 0.8s复原刚关掉的面板关掉后 6 秒内有效
左手握拳缩小页面（Ctrl+-）默认开启；左手握拳不再退放映，可在设置里关掉
左手张开手掌 · 停住 0.8s放大页面（Ctrl+=）同上，默认开启
双手食指伸出+中指收拢 · 比框识别框内文字稳住 1 秒自动截图识别

常见问题

点了「启动引擎」没反应？

看运行日志。没输出＝摄像头被别的程序占了（微信/Zoom/相机）；有输出但 PPT 不动＝PPT 没拿到焦点，重新点一下放映画面。

预览窗是黑的？

摄像头被占用，或系统没给「桌面应用」相机权限：设置 → 隐私和安全性 → 相机 → 允许桌面应用访问。

英文框选了却没有翻译？

翻译与详细讲解需要大模型（DeepSeek / 千问任一）。在「设置」里填自己的 API Key；不填只能查内置 50 条术语库。

换个人就不好用了？

已按手掌尺寸归一化：手大手小、坐远坐近都不用重调参数。若仍不灵敏，把手往摄像头靠近些（画面里太小的手不参与判定），或调大「取景框放大」。

框够不到屏幕边缘？

设置 → 取景框放大 → 调到 1.8 或 2.0（最大 2.5）。越大越省力，但同一手势对应的屏幕位移也越大，更难停准。

怎么卸载？

设置 → 应用 → 已安装的应用 → 搜 Gesto → 卸载。你的设置与日志在 %LOCALAPPDATA%\Gesto，不会被删。
