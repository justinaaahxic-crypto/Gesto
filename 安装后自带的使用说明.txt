Gesto — 手势演示控制台  v1.0.4
==================================================

一、怎么启动
    双击本文件夹里的 Gesto.exe 即可。不需要装 Python，不需要联网。

    想放到桌面：
        右键 Gesto.exe  →  发送到  →  桌面快捷方式
    （图标会自动带上 Gesto 的蓝紫 logo）

    想发给别人：
        把整个 Gesto 文件夹压缩成 zip 发过去，对方解压后双击 Gesto.exe 就能用。
        ⚠ 必须整个文件夹一起拷，不能只拷 Gesto.exe 一个文件。


二、第一次用（30 秒）
    1. 打开 Gesto.exe，停在「控制台」页
    2. 先打开你的 PPT，按 F5 进入放映
    3. 回到 Gesto 点「启动引擎」——注意：这时会打开一个摄像头预览小窗
    4. 5 秒倒计时内，用鼠标点一下 PPT 放映画面
       （模拟按键只发给当前前台窗口，不点就会「看起来没反应」）
    5. 对着摄像头比手势


三、手势（任何一只手都能用，不要求左右手）

    【任意单手】管翻页、关页面、复原
    五指张开向左划 ......... 下一页
    五指张开向右划 ......... 上一页
    食指+中指（其余收拢）划 . 连翻模式，冷却更短，适合连翻好几页
    握拳 ................... 面板开着就收面板；没面板就退出放映（Esc）
    2.5 秒内连握两次 ....... 回到桌面
    张开手掌并停住 0.8 秒 ... 复原刚被关掉的那块面板

    【左手】缩放（默认开启；不要可在设置里关掉）
            左右手按手型几何判定（拇指与小指的相对位置），不依赖模型标签；如判反了可在设置里取消「左右手判定互换」
            （浏览器里是 Ctrl+减 / Ctrl+等）
    握拳 ................... 缩小页面一档（不会退放映）
    张开手掌并停住 0.8 秒 ... 放大页面一档

    【双手】取景读屏
    食指伸出 + 中指收拢，两手比框 → 稳住 1 秒 → 识别框内文字

    位移阈值按手掌大小自动缩放，手大手小、坐远坐近都不用重调。
    手在画面里太小（太远）时不判动作，走近一点即可。
    位移阈值按手掌大小自动缩放，手大手小、坐远坐近都不用重调。
    手在画面里太小（太远）时不判动作，走近一点即可。
    连续同方向挥可以连翻，手回位那一下不会被误翻。
    想翻回上一页：手停 0.2 秒，再往反方向挥（停太短会被当成手在回位）。

    关于「复原」：握拳收掉面板后 6 秒内有效，相当于浏览器的 Ctrl+Shift+T。
    要点是「停住」——张开手横着扫是翻页，只有静止不动才算复原，所以两者不会打架。

    确认左右手没判反：摄像头预览窗左上角会显示 HAND: L / R。
    如果反了，在启动前设环境变量 HAND_SIDE_SWAP=1。

五、大模型（可选）
    本机安装包不含 API Key，第一次用请自己填：
        设置 → 填 API Key → 点「测试连通性」→ 保存并应用 → 重启引擎
    DeepSeek 的 Key 在 platform.deepseek.com 申请，充 10 块钱能用很久。
    不填也能跑，只是框到英文时没有中文翻译和详细讲解，只能查内置术语库。


六、常见问题
    Q: 点了「启动引擎」但手势没反应
    A: 先看「运行日志」最后一行有没有 [SLIDE] 之类输出。
       - 没有输出   → 引擎没起来，多半是摄像头被别的程序占了（微信/Zoom/相机）
       - 有输出但 PPT 不动 → PPT 没获得焦点，重新点一下放映画面
    Q: 预览窗是黑的
    A: 摄像头被占用。把其它用摄像头的程序全关掉，再重启引擎。
      另外检查：Windows 设置 → 隐私和安全性 → 相机 → 允许桌面应用访问相机。
    Q: 框选到了但识别不出字
    A: 框太小或太散。把框收紧到只框住那几行字；或者把「取景框放大」调大一点。
    Q: 框够不到屏幕边缘
    A: 设置 → 取景框放大 → 调到 1.8 或 2.0（最大 2.5）。越大越省力但越难停准。
    Q: 翻页方向反了
    A: 设置 → 翻页方向 → 选「左滑 = 上一页」→ 保存 → 重启引擎。
    Q: 面板关掉之后想再看一眼
    A: 6 秒内把手张开并停住 0.8 秒，面板会原样回来（不用重新比框等识别）。


七、文件和配置在哪
    程序本体 ........ 本文件夹（可整个搬到别处，路径随意）
    配置与日志 ..... C:\Users\<你的用户名>\AppData\Local\Gesto\
                      config.json  设置
                      engine.log   引擎日志（出问题可以直接发这个文件）
    取景框放大倍数 .. 也可以直接在摄像头预览窗里按 ] 放大、[ 缩小

    注意：程序文件夹是只读的，改设置请用界面里的「保存并应用」。
